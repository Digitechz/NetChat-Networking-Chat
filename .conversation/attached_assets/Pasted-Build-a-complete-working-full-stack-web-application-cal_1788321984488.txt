5. REAL-TIME CHAT

This is the most important feature.

Use WebSocket communication.

Architecture:

CLIENT A
    |
    | WebSocket
    v
SERVER
    |
    | WebSocket
    v
CLIENT B

When Alice sends a message to Bob:

1. Alice's client creates a message.
2. Send the message through WebSocket to the server.
3. Server validates the sender.
4. Server stores the message in SQLite.
5. Server checks whether Bob is online.
6. If Bob is online, send the message through Bob's WebSocket.
7. Bob's UI immediately displays the message.

Do NOT simulate this only on the frontend.
